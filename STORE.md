## Long description

_(store detailed description)_

GitHub Enhance makes GitHub nicer to look at and work with, especially the pull
request page. Every feature is optional and configured from a single popup, and
all colors come from GitHub's own theme, so it looks right in light, dark,
dimmed, and custom themes.

■ Pull request redesign (on by default)
A clean, card-based pull request page:
• The page and top header share one background.
• Sidebar sections, the checks and merge box, comments, the comment editor, and
  each changed-file block become rounded cards with subtle borders.
• The navigation tabs (Conversation, Commits, Checks, Files changed) become
  pill buttons.
• The merge box takes on its status color: green when checks pass, with matching
  accents for other states.

■ Absolute dates
Replace relative dates like “3 days ago” with the exact date and time. Pick the
date and time formats independently, and optionally drop the year for dates in
the current year.

■ Sidebar controls
Hide any pull request or issue sidebar section you never use, each with its own
toggle: Reviewers, Assignees, Labels, Projects, Milestone, Development,
Notifications, Participants, and Lock conversation.

■ One-click hide
Adds a Hide button that collapses a comment as “outdated” in one click, plus an
Unhide button to bring it back.

■ Layout tweaks
• Move the checks and merge box up: above the timeline on narrow screens, or
  into the sidebar on wide ones.
• Move the comment box to the top of the conversation.
• Hide the Community Guidelines and ProTip notices.
• Set the sidebar width and the overall page width with sliders.

■ Fully configurable
Turn any feature on or off and adjust its options from the popup. Keep only the
small tweaks and disable the redesign, or keep only the redesign. Nothing is
forced.

■ Privacy
Runs only on github.com and stores only your settings, synced by your browser.
No accounts, no tracking, no external servers, no data collection.
