## Long description

_(store detailed description)_

GitHub Enhance makes GitHub nicer to look at and work with — most of all the
pull request page. Everything it does is optional and configured from a single
popup, and every color is taken from GitHub's own theme, so it looks right in
light, dark, dimmed, and custom themes alike.

■ Pull request redesign (on by default)
Turns the pull request page into a clean, card-based layout:
• The page and the top header share one background, so the page feels unified.
• Sidebar sections, the checks / merge box, comments, the comment editor, and
  each changed-file block become rounded cards with subtle borders.
• The navigation tabs (Conversation, Commits, Checks, Files changed) become
  pill buttons.
• The merge box takes on its status color — green when everything passes, with
  matching accents for other states.

■ Absolute dates
Replace vague relative dates like “3 days ago” with the exact date and time.
Pick your date format and time format independently, and optionally drop the
year for dates in the current year.

■ Sidebar controls
Hide the pull request / issue sidebar sections you never use — Reviewers,
Assignees, Labels, Projects, Milestone, Development, Notifications,
Participants, and Lock conversation — each with its own toggle.

■ One-click hide
Adds a Hide button that collapses a comment as “outdated” in one click, and an
Unhide button to bring it back.

■ Layout tweaks
• Move the checks / merge box up — above the timeline on narrow screens, or
  into the sidebar on wide ones.
• Move the comment box to the top of the conversation.
• Hide the Community Guidelines and ProTip notices.
• Set the sidebar width and the overall page width with sliders.

■ Fully configurable
Open the popup to turn any feature on or off and adjust its options. Nothing is
forced — disable the redesign entirely if you only want the small tweaks, or
turn everything else off and keep just the redesign.

■ Privacy
GitHub Enhance runs only on github.com and only stores your settings (synced by
your browser). No accounts, no tracking, no external servers, no data
collection.
